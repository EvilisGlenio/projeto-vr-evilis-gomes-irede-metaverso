# ZenVerse

ZenVerse é um parque virtual de relaxamento desenvolvido em Unity como parte da Trilha 1 do projeto. A proposta é oferecer um ambiente imersivo, calmo e contemplativo, pensado para exploração livre, redução de estresse e sensação de bem-estar.

## Sobre o projeto

O ambiente foi construído com inspiração em bosques e parques tranquilos, reunindo elementos naturais para criar uma experiência visual acolhedora em realidade virtual.

Principais elementos do cenário:

- Terreno de aproximadamente `30x30`
- Árvores, pedras e arbustos distribuídos pelo mapa
- Pequeno lago central
- Bancos ao redor do ambiente
- Iluminação suave para simular uma tarde ensolarada com muitas nuvens

## Objetivo

Criar um espaço virtual imersivo para relaxamento, permitindo que o usuário explore um cenário natural e tranquilo dentro de uma experiência VR.

## Aprendizados

Durante o desenvolvimento, o projeto mostrou na prática como ambientes virtuais podem ser utilizados para promover relaxamento, contemplação e bem-estar.

## Dificuldades encontradas

- O processo de terraformação do terreno foi uma das etapas mais desafiadoras
- Foi necessário buscar apoio em vídeos e referências externas para evoluir essa parte
- Houve problemas no simulador durante os testes, o que dificultou a validação da experiência

## Melhorias planejadas

- Adicionar sons ambientes para aumentar a imersão
- Incluir fundo com montanhas ou outros elementos naturais
- Criar interações simples no cenário
- Explorar mecânicas como pesca no lago

## Tecnologias utilizadas

- `Unity 6` (`6000.3.13f1`)
- `Meta XR SDK`
- `OpenXR / Meta OpenXR`
- `Input System`
- `HDRP` e `URP` presentes no projeto
- `Terrain Tools`

## Estrutura relevante

- Cena principal: `Assets/Scenes/ZenVerseScene.unity`
- Documentação original: `Documentação.txt`

## Como abrir o projeto

1. Abra o projeto pelo `Unity Hub`
2. Utilize a versão `6000.3.13f1` da Unity
3. Carregue a cena `Assets/Scenes/ZenVerseScene.unity`
4. Configure os dispositivos XR, se desejar testar a experiência em VR
