# ZenVerse

ZenVerse e um parque virtual de relaxamento desenvolvido em Unity como parte da Trilha 1 do projeto. A proposta e oferecer um ambiente imersivo, calmo e contemplativo, pensado para exploracao livre, reducao de estresse e sensacao de bem-estar.

## Sobre o projeto

O ambiente foi construído com inspiracao em bosques e parques tranquilos, reunindo elementos naturais para criar uma experiencia visual acolhedora em realidade virtual.

Principais elementos do cenario:

- Terreno de aproximadamente `30x30`
- Arvores, pedras e arbustos distribuidos pelo mapa
- Pequeno lago central
- Bancos ao redor do ambiente
- Iluminacao suave para simular uma tarde ensolarada com muitas nuvens

## Objetivo

Criar um espaco virtual imersivo para relaxamento, permitindo que o usuario explore um cenario natural e tranquilo dentro de uma experiencia VR.

## Aprendizados

Durante o desenvolvimento, o projeto mostrou na pratica como ambientes virtuais podem ser utilizados para promover relaxamento, contemplacao e bem-estar.

## Dificuldades encontradas

- O processo de terraformacao do terreno foi uma das etapas mais desafiadoras
- Foi necessario buscar apoio em videos e referencias externas para evoluir essa parte
- Houve problemas no simulador durante os testes, o que dificultou a validacao da experiencia

## Melhorias planejadas

- Adicionar sons ambientes para aumentar a imersao
- Incluir fundo com montanhas ou outros elementos naturais
- Criar interacoes simples no cenario
- Explorar mecanicas como pesca no lago

## Tecnologias utilizadas

- `Unity 6` (`6000.3.13f1`)
- `Meta XR SDK`
- `OpenXR / Meta OpenXR`
- `Input System`
- `HDRP` e `URP` presentes no projeto
- `Terrain Tools`

## Estrutura relevante

- Cena principal: `Assets/Scenes/ZenVerseScene.unity`

## Como abrir o projeto

1. Abra o projeto pelo `Unity Hub`
2. Utilize a versao `6000.3.13f1` da Unity
3. Carregue a cena `Assets/Scenes/ZenVerseScene.unity`
4. Configure os dispositivos XR, se desejar testar a experiencia em VR
